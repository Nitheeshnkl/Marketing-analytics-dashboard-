# Marketing Analytics Dashboard

A comprehensive marketing analytics dashboard built with React, Flask, and Recharts.

## Features

- Real-time marketing metrics tracking
- Campaign management with budget tracking
- Revenue analytics and forecasting
- Conversion funnel analysis
- Channel performance analytics
- Data export to CSV
- Responsive design for all devices
- Dark mode interface

## Tech Stack

**Frontend:**
- React 18
- Tailwind CSS
- Recharts for data visualization
- Lucide Icons

**Backend:**
- Flask
- Flask-CORS
- Python 3.8+
